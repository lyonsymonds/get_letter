# 开信 — 一次性 / 重复性留言提取系统

一个「开信」风格的留言传递网站。用户创建留言后生成唯一验证码，对方输入验证码即可查看留言内容。

## 📖 项目介绍

### 核心功能

- **一次性消息创建** — 留言仅能被提取 1 次，提取后自动删除
- **重复性信息创建** — 设定最大提取次数（如 10 次），用完自动失效
- **输码提取消息** — 输入验证码快速提取留言

### 支持的消息类型

- 纯文本留言（最多 500 字）
- 二维码图片（≤1MB）
- 文字 + 二维码同时显示

### 验证码规则

- 格式：6 位数字 + 2 位字母（如 `482913AF`）
- 第 7 位为校验位（6 位数字之和 mod 26），前端即时校验格式
- 第 8 位为随机字母，用于防碰撞
- 提取页 `/e/CODE` 可直接访问查看留言

## 🛠 技术路径

### 后端

- **Node.js + Express** — 单文件 API 服务
- **SQLite** — 单文件数据库，零配置
- **限流** — IP 级别每分钟 5 次提取尝试

### 前端

- **原生 HTML + Tailwind CSS CDN** — 无需编译，即开即用
- **JavaScript 原生** — fetch API 与后端通信

### 部署

- 前端 → **GitHub Pages**（免费静态托管，国内可达）
- 后端 → **Vercel Serverless**（免费函数 + 免费 Postgres）
- 源码统一存于 **GitHub 仓库**，push 即自动部署

## 🎨 设计风格

- **视觉**：深色模式，径向渐变背景 `#0a0e1a` → `#151a2b`
- **配色**：深色背景 + 品红强调 `#ff4d8a`，灰色文字
- **布局**：三模块单页式（顶部输码提取 → 一次性创建 → 重复性创建）
- **字体**：`PingFang SC` / `HarmonyOS Sans` / 系统 sans-serif
- **Logo**：深蓝色线条锁图标（`logo.png`，项目根目录）


## 🔧 部署配置

### GitHub Pages + Vercel

2. 前端 → GitHub Pages（选 `public/` 目录）
3. 后台 → Vercel（关联 GitHub，自动部署）
4. 前端接口指向 Vercel 的 API 地址
